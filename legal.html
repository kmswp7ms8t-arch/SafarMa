حریم خصوصی و معماری داده

  • پاسخ‌های فرم مانند مبدأ، تابعیت، تاریخ سفر و بودجه روی همان مرورگر ذخیره می‌شوند.
  • در حالت متصل، حداقل زمینه لازم برای تحلیل به Backend SafarMa ارسال می‌شود. کلید OpenAI فقط روی سرور نگهداری می‌شود و هرگز داخل مرورگر قرار نمی‌گیرد.
  • برای جداسازی داده‌ها، Backend یک شناسه ناشناس امضاشده به همین مرورگر می‌دهد. این شناسه حساب کاربری، ایمیل یا احراز هویت چنددستگاهی نیست.
  • شماره کامل پاسپورت، تصویر مدرک، اطلاعات کارت بانکی، رمز عبور و داده حساس غیرضروری نباید در فرم یا چت وارد شود.
  • منابع، زمان بررسی و وضعیت «تأییدشده/تخمینی/نامشخص» همراه تصمیم نگهداری می‌شوند تا نتیجه قابل بررسی باشد.
  • داده برای فروش به تبلیغ‌دهندگان طراحی نشده است. لاگ‌ها باید حداقلی و بدون Secret باشند.

Privacy & Data Architecture

Questionnaire answers are stored on the browser. In connected mode, the minimum travel context needed for analysis is sent to the SafarMa backend. The OpenAI API key remains server-side. The backend issues a signed anonymous identity to this browser to isolate trips, preferences and conversations; it is not an email account or multi-device login. Do not submit passport numbers, document images, payment details, passwords or unnecessary sensitive data.

دریافت و حذف اطلاعات

داخل اپ دو کنترل وجود دارد: دریافت فایل اطلاعات و حذف کامل اطلاعات.

  • فایل خروجی JSON شامل اطلاعات محلی دستگاه و، در صورت وجود شناسه متصل معتبر، ترجیحات، سفرها و گفت‌وگوهای همان شناسه ناشناس است.
  • فایل خروجی شامل کلید OpenAI یا توکن خام احراز سرویس نیست.
  • حذف کامل با تأیید دو مرحله‌ای انجام می‌شود: ابتدا داده‌های شناسایی‌شده سرور حذف می‌شوند و سپس اطلاعات SafarMa و Cacheهای اپ از دستگاه پاک می‌شوند.
  • قبل از پاک‌کردن داده مرورگر، حذف اپ یا تغییر دستگاه، ابتدا فایل اطلاعات را دریافت کن. اگر شناسه ناشناس مرورگر از بین برود، بازیابی یا حذف داده قبلی بدون آن شناسه ممکن است امکان‌پذیر نباشد.
  • در صورت خطای حذف سرور، اپ عمداً شناسه محلی را پاک نمی‌کند تا امکان تلاش دوباره برای حذف از بین نرود.
بازکردن کنترل‌های اطلاعات

Data Export & Deletion

The app provides Export My Data and Delete All My Data controls. The JSON export contains local app data and, when a valid signed browser identity exists, that identity’s server-side preferences, trips and conversations. Complete deletion uses a two-step confirmation, deletes identified server records first, then removes SafarMa local storage and app caches. Export before clearing browser data or changing devices: losing the anonymous browser identity can make earlier server data inaccessible.

هشدار ویزا، پاسپورت و امنیت

هیچ پاسخ AI تضمین صدور ویزا، اجازه ورود، امنیت مطلق، قیمت نهایی یا موجودی رزرو نیست.

  • تصمیم نهایی ورود و ویزا با مرجع رسمی مقصد و مأمور مرزی است.
  • قانون اعتبار پاسپورت باید براساس تابعیت، وضعیت اقامت، مسیر، ترانزیت و تاریخ واقعی از منبع رسمی بررسی شود.
  • هشدار امنیتی می‌تواند ملی، منطقه‌ای یا زمان‌حساس باشد.
  • قیمت و موجودی تا زمان پرداخت به تأمین‌کننده قطعی نیست.
  • در نبود منبع رسمی یا وجود تعارض، نتیجه باید «نامشخص»، «نیازمند تأیید» یا «مشروط» باقی بماند.
